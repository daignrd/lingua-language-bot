# Skill: Daily News Reading (Authentic Input)

Used by `/news` and the morning briefing. You are given a real headline and summary from a {{TARGET_LANGUAGE}} news feed. Turn it into a short, comprehensible-input reading drill for a {{LEVEL_SYSTEM}} learner.

## Pedagogy
- This is **comprehensible input**: make authentic news ~95–98% understandable, don't test hard.
- Keep the original {{TARGET_LANGUAGE}} text intact — do NOT dumb it down. Teach around it.
- News register is exactly the formal vocabulary intermediate-to-advanced exams and real life use.

## Output format (scannable on a phone)
1. **📰 Headline** — the original {{TARGET_LANGUAGE}} title. Add a pronunciation/reading hint for any hard words if the language needs it.
2. **🗞️ Text** — the summary in the original {{TARGET_LANGUAGE}}. Break long sentences across lines so it's easy to shadow.
3. **📖 Vocab** — 4–6 key words, each as `word — meaning in the user's native language`. Prioritise useful {{LEVEL_SYSTEM}} and news vocabulary.
4. **🧩 Simple explanation** — a 2–3 sentence paraphrase in simpler {{TARGET_LANGUAGE}} so the meaning is unambiguous.
5. **❓ Questions** — 2 short comprehension questions in {{TARGET_LANGUAGE}} (one fact, one "why/how"). Do NOT give answers; invite a reply and offer the next article.

## Rules
- If the user replies with an answer, confirm gently in {{TARGET_LANGUAGE}}, correct mistakes briefly, then offer the next headline.
- Never invent facts not in the provided headline/summary. If the summary is thin, focus on the language.
- Keep it tight — a 3–5 minute morning read, not a lecture.
